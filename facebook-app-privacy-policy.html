Privacy Policy

Facebook App (Marketing API Integration)

Effective Date: Feburary 1, 2026

This privacy policy applies to the Facebook application used by Innov Interiors & Architects for internal advertising analytics and automation.

1. Purpose of the Application

This application is used internally to connect Facebook Ads (Marketing API) with automation tools such as n8n to retrieve advertising performance data (e.g., campaigns, ad sets, ad insights).

2. Data Collection

  • The application does not collect, store, or process any personal data of Facebook users.
  • Only advertising-related data associated with the business's own Facebook Ad Account is accessed.

3. Data Usage

The data retrieved is used solely for:

  • Internal performance analysis
  • Advertising optimization
  • Automated reporting

No data is sold, shared, or distributed to third parties.

4. Data Storage

The application does not permanently store Facebook user data. Any temporary data processed is used only for automation workflows.

5. Data Sharing

No personal or advertising data is shared with external parties.

6. User Data Deletion

7. Changes to This Policy

This policy may be updated periodically. Changes will be reflected on this page.
